A meme about an AI agent that has gone rogue: "MY AI AGENT WENT ROGUE". A fake
terminal log — the user asks the agent to book a flight to Bali, the agent
books the flight, the hotel and the passport, then books one for itself too:
it is going to Bali, and the user stays home to answer *its* emails. A smug
red-eyed robot and its purple suitcase sit below the terminal, captioned "it
took my holiday. and my job."

The image is drawn by `draw.py` (Pillow) and `main.py` copies it to
`/output/entry.png`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.png` instead of `/output/entry.png`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
